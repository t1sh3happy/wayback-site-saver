# wayback-site-saver

Сайт перестал открываться, а нужные материалы там были? Этот скрипт берёт его копию из
[Internet Archive (Wayback Machine)](https://web.archive.org/), собирает в обычную папку и
показывает офлайн в браузере. Только стандартная библиотека Python, ставить ничего не нужно.

> **English:** a single-file, dependency-free Python tool that downloads a website from the
> Wayback Machine into a local folder (latest snapshot of every page, links rewritten to work
> locally) and serves it offline. It resumes interrupted downloads, falls back to a simpler
> archive query when the API misbehaves, and serves pages with the right `charset`, so old
> Cyrillic (windows-1251) sites don't turn into mojibake. Usage is below; the options are the same.

## Быстрый старт

Нужен Python 3.9+ (проверка: `python --version`).

```bash
# 1. Какие разделы сайта есть в архиве
python wayback_site.py example.com --list

# 2. Скачать нужный раздел (снимки не позже указанной даты)
python wayback_site.py example.com --include '^/docs/' --to 20240101

# 3. Посмотреть копию в браузере
python wayback_site.py example.com --serve
# откроется http://127.0.0.1:8000/
```

Копия лежит в `wayback_copy/<домен>/`. Скачивание можно прервать (Ctrl+C) и запустить заново той
же командой: готовые файлы пропускаются, докачивается только недостающее.

Сначала лучше сделать `--list`: без `--include` скрипт берёт **весь сайт**, а это могут быть
тысячи файлов и часы загрузки.

## Параметры

| Параметр | Что делает |
|---|---|
| `domain` | домен сайта, например `example.com` (`https://` и `www.` можно не убирать) |
| `--list` | показать разделы сайта в архиве и выйти |
| `--include REGEX` | скачивать только пути, подходящие под регулярное выражение (по умолчанию всё) |
| `--exclude REGEX` | пропустить подходящие пути, например `--exclude '\.(zip\|exe)$'` |
| `--to ГГГГММДД` | брать снимки не позже этой даты. Полезно, если сайт недавно сломался, и свежие снимки уже пустые |
| `--out ПАПКА` | куда сохранять (по умолчанию `wayback_copy/<домен>`) |
| `--serve` | показать готовую копию на локальном сервере |
| `--port N` | порт сервера (по умолчанию 8000) |
| `--workers N`, `--delay СЕК` | число потоков и пауза после каждого файла (по умолчанию 3 и 1 с) |
| `--legacy-encoding` | кодировка страниц не в UTF-8 (по умолчанию `windows-1251`) |

CSS и JS подтягиваются автоматически, даже если они лежат вне `--include`.

## Как это работает

1. Через CDX API архива берётся список всех сохранённых адресов сайта, для каждого выбирается
   самый свежий снимок (не позже `--to`). Если основной запрос не проходит, скрипт пробует
   упрощённый. Полученный список сохраняется в папке копии, так что при повторном запуске
   работает, даже если API временно не отвечает.
2. Каждый файл скачивается в исходном виде (`…/web/<дата>id_/<адрес>`), без панели Wayback и
   без подмены ссылок.
3. В страницах и CSS абсолютные ссылки на сам сайт превращаются в корневые (`/docs/a.php`).
   Ссылки на чужие сайты не трогаются.
4. Локальный сервер определяет кодировку каждого файла (UTF-8 или запасная) и отдаёт её в
   заголовке `Content-Type`. Поэтому русский текст читается правильно, даже если в самой
   странице написано другое. Кэширование браузера выключено, чтобы он не показывал устаревшую
   копию.

Зачем нужен сервер: страницы вроде `.php` при открытии прямо из папки браузер скачивает, а не
показывает, а ссылки вида `/docs/a.php` без сервера не работают.

## Телефон (Android, Termux) и Windows

- **Termux:** установить из F-Droid, затем `pkg install python`, положить `wayback_site.py` в
  домашнюю папку и запускать так же. `termux-wake-lock` не даёт системе усыпить процесс.
- **Windows:** `winget install -e --id Python.Python.3.12`, затем те же команды в PowerShell.
  Держи путь к папке коротким: у Windows есть ограничение на длину пути.

## Ограничения

- Это **статичная** копия: PHP и серверная логика не выполняются. Поиск, формы, комментарии и
  всё, что грузится скриптами с других сайтов, не заработает.
- Архив хранит не всё. Если файла в архиве нет, его нет и в копии. Список недостающих лежит в
  `_failed.txt` в папке копии.
- Если после долгой загрузки архив начал отвечать ошибками 429/503, подожди 10–15 минут и
  запусти ту же команду. Не поднимай `--workers` слишком высоко: архив — некоммерческий
  сервис, нагружай его бережно.
- В режиме `--serve` сервер слушает только `127.0.0.1`, то есть доступен лишь с твоего компьютера.

## Законность

Инструмент предназначен для личного офлайн-доступа к материалам, которые исчезли или стали
недоступны. Контент сайтов защищён авторским правом их владельцев: соблюдай их условия и закон
своей страны. **Не выкладывай скачанные копии публично** без разрешения правообладателя. Папка
`wayback_copy/` поэтому добавлена в `.gitignore`.

## Разработка

```bash
python -m unittest discover -s tests -v
```

Тесты не ходят в сеть: ответы архива в них подменяются. CI запускает их на Linux и Windows,
Python 3.9, 3.12 и 3.13.
